# 青岛理工大学信控学院实验室飞行器队伍

### 引言

青岛理工大学飞行器队自用。

为便于内容梳理和发展传承，书写本文。

在队伍更替、队长交接时，完成移交。

暂主要介绍飞行器队伍历程和摄像头学习路径。

也希望后续队伍队长能继续补充拓展，不论在此文档补充，还是移植至借助git的github、gitee等，使之历年完善，留下每一代人的足迹。

仓促而就，难免有误，不便外传，以免贻笑大方。

---

### 2026年10月30日｜续写引言

2018年3月，青岛理工大学整合原计算机工程学院、通信与电子工程学院和自动化工程学院，组建信息与控制工程学院。不同专业的学生由此汇聚，在共同的实验室中学习、探索、协作。飞行器队伍也在一代代成员的努力下逐步发展，成为这段历史的见证者。

2025年9月，学校启动人工智能学院筹建工作。2026年初，学校再次调整学院与学科布局，原信控学院的专业重新划分：电子信息工程、通信工程等专业归入人工智能学院；自动化、电气工程及其自动化、建筑电气与智能化等专业继续归属信息与控制工程学院。至此，曾经同属信控学院的专业走向了不同的发展方向，昔日共同的学院归属，也成为一段历史。

**学院可以调整，专业可以分流，但共同走过的历史不应被割裂。** 那些曾在同一间实验室并肩奋斗的身影，那些历经数届积累的技术与经验，不应随着院系变迁而逐渐淡去。正因如此，2026年重新整理这份文档，继续沿用“青岛理工大学信控学院实验室飞行器队伍”这一历史名称。它所承载的，不只是一个学院的名字，更是一代代成员共同的归属与记忆。

回望来路，方知今日之所从来。前辈留下的文字、技术与精神，是后来者得以继续前行的根基。愿这份记录能够跨越学院的更迭与岁月的流转，保存那些不应被遗忘的人与事。也愿后来者接续书写，使每一代人的努力都有迹可循，每一段奋斗的岁月都有处可寻。

## 资料内容

本仓库整理飞行器队伍的发展历程、软硬件学习资料、参考例程及历年任务安排。后续可根据实际维护情况继续扩充。

- **`development/`：** 队伍发展历程、历届成员与技术传承（详见《发展历程.md》）。
- **`introduction/`：** 飞行器相关软硬件介绍和入门学习资料。
- **`Reference/`：** 相关参考资料与例程；其中 `example_N` 表示与编号 N 对应的例程，`bin` 表示灰度或二值化图片，`rgb` 表示 RGB 彩色图片，中间名称描述功能，文件名末尾数字标记版本。
- **`task/`：** 按年份整理的任务与安排。
- **`README.md`：** 本文档，介绍队伍背景与资料组织方式。
